# Release Notes

## v1.1.1

根据实际使用反馈，回撤两项观感比较怪的趣味功能，并优化菊花梨的自主移动方式。

### 调整内容

- 移除迷你键盘模式。
- 移除躲到任务栏下的行为。
- 右键菜单中的“让菊花梨散步”改为“让菊花梨踱步”。
- 自主移动改为更短距离、更慢速度的小范围踱步。
- 踱步时加入轻微上下起伏和步伐节奏，减少直接平移的感觉。

## v1.1.0

增加一组趣味互动，让菊花梨更像会自己玩的小桌宠。

### 新增内容

- 待机时更频繁地自主溜达。
- 偶尔会躲到任务栏下，只露出一部分身体。
- 右键菜单新增“让菊花梨散步”“躲到任务栏下”“开心跳一下”。
- 新增迷你键盘模式。
- 按下迷你键盘上的常用键时，菊花梨会跳到对应按键上。
- 迷你键盘按键会短暂高亮，只用于动画反馈，不记录输入内容。

## v1.0.3

优化提醒弹窗布局。

### 修复内容

- 增大提醒窗口尺寸，避免底部按钮被裁切。
- 将提醒弹窗改为标题、内容、按钮分区布局。
- 待办内容放入独立浅色区域，长文本更容易阅读。

## v1.0.2

优化添加待办窗口布局。

### 修复内容

- 将日期和时间输入改为并排布局。
- 缩短表单纵向高度，避免时间输入被底部按钮遮住。
- 保持原有待办创建和提醒逻辑不变。

## v1.0.1

修复 Windows 独立版只下载单个 exe 后无法显示的问题。

### 修复内容

- 将 WPF 原生运行库打入单文件自解压包。
- 下载 `JuHuaLiPet.exe` 后不再需要额外 DLL。
- 隔离目录中只保留 exe，运行 20 秒验证通过。

## v1.0.0

- Windows 独立桌宠：`JuHuaLiPet.exe`

- WPF 源码
- 使用文档

### 主要功能

- 桌面透明悬浮宠物
- 左键拖动
- 双击互动
- 待机随机动作
- 自动小范围溜达
- 多段专属音效
- 待办事项
