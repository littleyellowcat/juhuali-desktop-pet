# Release Notes

## v1.0.3

优化提醒弹窗布局。

### 修复内容

- 增大提醒窗口尺寸，避免底部按钮被裁切。
- 将提醒弹窗改为标题、内容、按钮分区布局。
- 待办内容放入独立浅色区域，长文本更容易阅读。

## v1.0.2

优化添加待办窗口布局。

### 修复内容

- 将日期和时间输入改为并排布局。
- 缩短表单纵向高度，避免时间输入被底部按钮遮住。
- 保持原有待办创建和提醒逻辑不变。

## v1.0.1

修复 Windows 独立版只下载单个 exe 后无法显示的问题。

### 修复内容

- 将 WPF 原生运行库打入单文件自解压包。
- 下载 `JuHuaLiPet.exe` 后不再需要额外 DLL。
- 隔离目录中只保留 exe，运行 20 秒验证通过。

## v1.0.0

首个公开整理版本。

### 包含内容

- Windows 独立桌宠：`JuHuaLiPet.exe`
- Codex Pets 自定义宠物包：`juhuali-codex-pet.zip`
- WPF 源码
- 使用文档

### 主要功能

- 桌面透明悬浮宠物
- 左键拖动
- 双击互动
- 待机随机动作
- 自动小范围溜达
- 多段专属音效
- 待办事项
- 到点提醒
- 大小和音量设置
